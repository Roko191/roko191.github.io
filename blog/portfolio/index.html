About me

Hello! My name is Roko, and I am currently a second-year student pursuing Computer Science, with a particular interest in the low-level of systems, from hardware design through to operating systems.

Recently, I have become more interested in security and exploitation techniques, having contributed to the OpenOrbis project by helping with the creation of tools for the PlayStation 4 and also contributing to the Formula Student software at my university.

I have also recently started exploring AI, mainly through hands-on experimentation — most notably integrating an LLM into a real-time traffic dashboard during a hackathon.

Projects

FESB Racing - Telemetry System

Designing and implementing telemetry and data logging systems for a Formula Student racecar. Created a Python WebSocket server to collect real-time data from the CAN bus and an Electron frontend to visualize the collected data. Added support for Kvaser SDK on Linux and KME file format parsing.

Blog post to writeup about working with KvaserSDK and handling large data here

OpenOrbis – PS4 Toolchain

Working on an open source PS4 homebrew development toolchain for systems level programming. Developed stubtool, a .NET 8.0 CLI utility that parses PS4 system binaries (.sprx, .prx, .dll), resolves their NIDs for various firmware versions, and produces stub libraries and C/C++ header files.

Admin Panel – Appointment Management System

Creating a complete web admin panel for handling client bookings and administrative processes. Built on Node.js, Express, and MongoDB, and employing EJS for server-side rendering. Basic functionality is in place, consisting of a scheduling system for booking clients and managing appointments, automatic text notifications through the Infobip API, and administration management through a system built with JWT authentication and custom login and email verification; email sending is done via NodeMailer. Additional future functionality includes the management of gift vouchers, further administrative functionalities, and an IoT API connection. It has been designed to be run locally using a Raspberry Pi and using Docker Compose to deploy three Docker containers including MongoDB, the web app, and an Nginx reverse proxy with mkcert-generated certificates for encrypted local traffic.

WordleHR

Creating a word guessing game in the Croatian language using TypeScript on the frontend with Vite and Tailwind CSS. The application was designed using clean architecture and is easily configurable by separating game rules from parsing of the game words using Hunspell.

Hunspell Parser

Python CLI tool for parsing Hunspell dictionary files and exporting word lists as JSON. Language-agnostic – works with any Hunspell-compatible dictionary.

Split // PROMETNI AGENT - SheepAI_ Hackathon

As part of a team, built a real-time urban mobility dashboard integrating live traffic data from Promet Split, NextBike bike-sharing API, and Overpass API into a unified map view. Users could report traffic incidents, with location validation via Overpass API to reject reports placed on water, forests, beaches, and similar invalid areas. Connected Llama 3.1 70B Instruct via NVIDIA NIM API using the OpenAI SDK as a conversational assistant for traffic insights Frontend built with Vite/Vanilla JS connected to Supabase, Python backend handling API aggregation and LLM integration. Personally responsible for LLM integration and system prompt engineering and connecting and dataprocessing from Promet Split webscoket server. Developed as a proof of concept with potential for further development into a more comprehensive urban mobility platform.
